# مَدار — AI Interactive Whiteboard Tutor

نموذج رياضيات الصف العاشر — الفصل الأول، مستند إلى الكتاب الأردني المرفق (132 صفحة).

## تشغيل Next.js محلياً

يتطلب Node.js 22.13+.

```bash
npm install
cp .env.example .env.local
# ضع OPENAI_API_KEY داخل .env.local — لا تضعه في المتصفح أو Git.
npm run dev:next
```

افتح http://localhost:3000. للإنتاج: `npm run build:next && npm run start:next`.

المشروع يستخدم Next.js App Router وReact وTypeScript. مسار النشر على Sites يستخدم Vinext لتشغيل نفس التطبيق على Workers. أوامر `dev` و`build` مخصصة لهذا المسار؛ أوامر `*:next` تستخدم Next.js نفسه.

## الحالة الصادقة

- معالجة فعلية للكتاب: 127 صفحة تعليمية من صفحة 6 إلى 132، مع نصوص وصور محفوظة. الصفحات 1–5 هي المقدمة وحقوق النشر والفهرس.
- تطابق أرقام الصفحات المطبوعة مع PDF تحقق لجميع الصفحات التعليمية.
- الاسترجاع BM25 عربي مع تطبيع ومرادفات وترجيح عناوين الدروس، وتوسيع الاستعلام بموديل لتغطية إعادة الصياغة وأسئلة المتابعة. ليس بحث embeddings ولا تُدّعى هذه الميزة.
- فصل فهم الصورة/تفريغ التسجيل عن الاسترجاع ثم توليد شرح JSON مُتحقق منه. لا توجد إجابات AI وهمية أو دروس ثابتة في التطبيق.
- المفتاح غير مرفق؛ بدون المفتاح يعمل تصفح الكتاب وتظهر رسالة اتصال واضحة. الاستدعاءات الحية للذكاء والصوت لم تُختبر لعدم توفر اعتماد حقيقي.
- اختبارات الخدمات تستخدم ناقلاً مزيفاً داخل `tests/` فقط، وتوضح ذلك بأسمائها. لا يتم تضمين هذا البديل في مسارات الإنتاج.
- الاختبارات الوظيفية والأنواع والبناء منفصلة عن QA البصري. بيئة معاينة المتصفح غير متاحة في هذه الجلسة، لذلك لا يوجد ادعاء بأن التخطيط خضع لتجربة بصرية فعلية على الأجهزة.
- الجلسة مجهولة؛ الحالة محفوظة خلال فتح الصفحة. التحديث يبدأ سبورة جديدة. لا حسابات ولا تخزين لصور الطالب أو صوته على القرص.

## إعادة فهرسة الكتاب

الفهرس والصور جاهزة ومرفقة ولا تحتاج Python عند تشغيل التطبيق.

```bash
pip install pymupdf
python scripts/ingest.py /path/to/textbook.pdf
```

لإضافة كتاب آخر إلى محرك المعالجة، مرّر `--catalog path/to/catalog.json`، وهو مصفوفة `[pdfStartPage, unitName, lessonName]`. راجع أرقام الصفحات المطبوعة بعد المعالجة. التطبيق الحالي مقصود لكتاب واحد فقط.

استخراج PDF قد يفصل الأسس والكسور، لذا احتُفظ بصورة الصفحة الأصلية ومؤشرات دقة الرياضيات. لا تُعامل النصوص المستخرجة على أنها OCR رياضي كامل. الكتاب يحدد المنهج، وقد يحل المعلم مسائل جديدة بطرقه دون أن يدّعي أنها اقتباسات منه.

## الصوت والصورة

- التسجيل عبر MediaRecorder يحتاج HTTPS أو localhost وإذن الميكروفون. يتوقف تلقائياً بعد دقيقة.
- الصور JPG/PNG/WebP حتى 8 MiB. الصوت حتى 12 MiB. فحص الحجم وMIME وتوقيع الملف على الخادم.
- القراءة البصرية قد تخطئ في الخط اليدوي؛ السؤال المستخرج ظاهر للتصحيح وإعادة الإرسال.
- الكلام على مستوى كل خطوة؛ لا يعمل صوتان معاً. عند تعذر الصوت يستمر الشرح المرئي مع تنبيه واضح.
- المعلم يستخدم صوتاً مولداً بالذكاء الاصطناعي مع الإفصاح في الواجهة.

## الأمان والتشخيص

الاعتمادات خادمية فقط. لا `eval` أو JavaScript يولده الموديل. الرسوم قائمة أعمال مسموحة مع Zod. HTML الوحيد المولد من KaTeX مضبوط بـ `trust:false`، والنص الآخر يهربه React. صور السبورة مقيدة بمراجع الاسترجاع. صفحات الكتاب ومعرفات مصادره يلصقها الخادم بعد التحقق.

`TUTOR_DIAGNOSTICS=true` يتيح لوحة تشخيص في development فقط: الاستعلام المطبع والمقاطع المسترجعة وJSON والأجسام الحالية. متغيرات الموفر معزولة في `lib/ai/provider.ts`.

حماية المعدل داخل الذاكرة مناسبة لنموذج خاص وليست محدداً موزعاً للإنتاج العام. لا تنشر بمفتاح مدفوع على جمهور مفتوح دون حدود استخدام دائمة مناسبة. النسخة الحالية لا تضيف تسجيل دخول للتطبيق.

حقوق الكتاب تبقى لناشره؛ هو مرفق المستخدم ومرجع النموذج، وليس محتوى أنشأه التطبيق.
