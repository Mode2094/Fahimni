# التقرير التنفيذي — جاهزية إطلاق فهمني

**الفرع:** `release/fahimni-production-readiness` (مبني على PR #2 ← PR #1).
**الفرع الرئيسي `main`:** لم يُمَس (`c8c2ff1`).
**الحكم النهائي:** **جاهز لاستخدام مقيّد (Pilot) — غير جاهز للإنتاج الكامل.**
السبب: نواقص خارجية تتطلّب قرارات المالك (الدفع، المحتوى المرخّص، بيئة النشر،
الاعتماد القانوني) وليست عيوبًا برمجية.

## ما أُنجز في هذا الفرع

1. **أمان الرصيد (أخطر مشكلة، P0):** كل عملية تغيير للرصيد صارت تُقفل صف المحفظة
   وتُعيد المحاولة عند التعارض، فلا فقدان تحديثات ولا أرصدة سالبة. تم التحقق على
   PostgreSQL حقيقي باختبارات تزامن.
2. **عزل رصيد الفصول (P0):** لكل فصل رصيد منفصل بتاريخ بداية وانتهاء خاصين؛ شراء
   الفصل القادم مبكرًا يحجز رصيده دون المساس بالرصيد الحالي أو تواريخه.
3. **ذكاء اصطناعي واعٍ بالمادة (P1):** أُزيلت افتراضات الرياضيات من كل المسارات
   (تعرّف الصور، الصوت، قواعد التدريس، التحقق الحتمي، الاسترجاع)؛ كل مادة تُعالج
   بمصطلحاتها.
4. **لوحة «جاهزية الإطلاق» (P1):** لوحة مشرف تعرض فحوصات حقيقية وإجراءً واضحًا
   لكل بند، دون إظهار أسرار أو حالات خضراء وهمية.
5. **مستندات قانونية كاملة (P1):** ثمانية مستندات عربية مطابقة للسلوك الفعلي،
   معلّمة صراحةً بأنها قيد المراجعة القانونية.
6. **مصفوفة جاهزية المنهاج وسجل النواقص:** توثيق كل ما هو جاهز وما هو ناقص.
